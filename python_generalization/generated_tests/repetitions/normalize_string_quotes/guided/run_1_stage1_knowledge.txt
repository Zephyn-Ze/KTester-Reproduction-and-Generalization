### Analysis of the `normalize_string_quotes` Function

1. **Input Structure and Constraints:**
   - **Inputs:**
     - `s`: A string representing the original string that may contain quotes and escape characters.
   - **Constraints:**
     - The string may start with any character from the defined `STRING_PREFIX_CHARS`.
     - The string must contain at least one quote character (`"` or `'`) following any prefix.
     - The function is designed to handle both raw strings (prefixed with `r`) and formatted strings (prefixed with `f`).

2. **Output Structure:**
   - The function returns a string that normalizes quotes in the input string `s`, preferring double quotes (`"`) over single quotes (`'`) while ensuring that escaping rules are respected.
   - If no changes are necessary, it returns the original string `s`.

3. **Important Branches and Conditions:**
   - The function has several branches based on the type of quotes present in the string:
     - If the string starts with `"""`, it returns the string as is.
     - If it starts with `'''`, it prepares to change the quotes to `"""`.
     - If it starts with a single quote, it prepares to change it to a double quote, and vice versa.
   - There are checks for:
     - Presence of unescaped quotes in raw strings.
     - Presence of unnecessary escape characters in the body of the string.
     - The condition of formatted strings where backslashes should not be introduced.

4. **Boundary and Edge Cases:**
   - Strings that are empty or contain no quotes.
   - Strings that consist solely of a prefix character followed by quotes (e.g., `f"""` or `r'''`).
   - Strings with quotes at the very end or beginning.
   - Strings with complex escaping scenarios (multiple backslashes, mixed quotes).
   - Edge case where a double quote is at the end of the new body string, which requires specific handling.

5. **Possible Exception Cases:**
   - The assertion `assert first_quote_pos != -1` will raise an `AssertionError` if no quote is found in the string, indicating a malformed input.
   - Potential regex compilation errors if invalid patterns are provided (though this is mitigated by the use of predefined patterns).

6. **Important Semantic Behaviors that Should Be Tested:**
   - Correct handling of strings with mixed quotes and escape characters.
   - The function should not introduce unnecessary escapes or change the meaning of raw strings.
   - The function should return the original string when no changes are necessary.
   - Verifying that formatted strings do not allow backslashes to be introduced incorrectly.
   - Ensuring that the output string maintains the semantics of the original string, especially in terms of escaping and quoting.
